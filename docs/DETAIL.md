# 会话内查找

在一个会话的问答记录里按关键字查找，比翻滚动条快。

## 行为

- `Ctrl+F`（macOS 为 `⌘F`）在会话区顶部、会话标题下方弹出查找条，输入即搜。
- 输入时只刷新命中数和高亮，**不抢焦点、不改动选区、不滚动**，可以连续输入不被打断。
- 所有命中都用黄色底色标出；当前命中的那一处用橙色底色区分。
- `Enter` 跳到下一个、`Shift+Enter` 上一个，↑ / ↓ 按钮同效；跳转时把命中滚到会话区中部。
- `Esc` 或 ✕ 关闭。查找条显示"第 n / 共 m"，无命中显示"无匹配"；命中超过 500 个时显示"共 500+"。
- 回复正在流式输出时命中数会自动刷新，保持当前项不跳到第一项；切换会话则重新开始查找。
- 查找条开启时 `Ctrl+F` 会回到输入框并全选，方便换关键词。

## 覆盖范围

- 大小写不敏感，按纯文本匹配，不区分标题/正文/代码块。
- 只匹配当前已渲染的会话内容（被折叠起来、没有渲染的内容不计入）。
- 高亮由浏览器原生绘制（CSS Custom Highlight API），跟着文字滚动、只出现在会话区内，不会盖到别的界面上。
- `Ctrl+Shift+F`（派生会话）与 `Ctrl+Alt+F` 不受影响。
